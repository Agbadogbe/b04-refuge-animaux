# Bilan individuel · Imhotep

## Mon niveau de départ

Au début du module, j'étais à l'aise avec la structure HTML et les bases de Git. Le CSS responsive, JavaScript, le DOM, les événements et les tests étaient à renforcer.

## Deux acquis prouvés

1. Je sais relier un élément du DOM à un événement et maintenir son état : le commit `95a44a7` ajoute un compteur accessible qui suit chaque frappe et revient à zéro après l'envoi.
2. Je sais appeler une route JSON avec `fetch`, `async/await` et un plan B en cas de panne : le commit `c2a2b52` fait répondre Cap Web à `conseil` sans écran blanc lorsque le serveur est arrêté.

## Deux points à renforcer

- Écrire davantage de tests navigateur ciblés pour les comportements asynchrones et les pannes réseau.
- Approfondir le CSS responsive pour concevoir des interfaces plus complexes sur plusieurs tailles d'écran.

## Mon objectif

Construire une prochaine fonctionnalité complète en petits commits, avec son test rouge d'abord, son implémentation, une vérification d'accessibilité et une revue de code externe.
